In Sketchware Pro, XMLStrings blocks allow you to work with strings stored inside your project's Android resource files (`res/values/strings.xml`). Storing text as XML resources makes it easy to translate your app into multiple languages and manage app-wide labels in one central place.

# Built-in XMLStrings Blocks

### get String from Res string: [res]
![get string from res](assets/xml-strings/get-string-from-res.png)

Retrieves the translated text value from your app's `strings.xml` resource file using the chosen resource identifier.

### Saved Res Strings : app_name
![saved res string](assets/xml-strings/saved-res-string.png)

A convenient shorthand block representing a saved string resource name (such as `app_name`). You can plug this directly into resource string input slots.
